##Introduction

A portfolio website serves as a digital resume and helps students and developers present their skills and achievements online. In this project, I created a static portfolio website that provides information about myself, my technical skills, academic background, projects, and contact details.

The website was developed using basic web technologies and follows a modern responsive design so that it can be viewed properly on desktops, tablets, and mobile devices.
